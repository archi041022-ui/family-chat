# Семья — мессенджер для своих

Чаты (общий «Семья», личные, группы), реакции, ответы, фото, видео, файлы,
голосовые сообщения, аудио- и видеозвонки. Работает в браузере и как приложение для Android.

- `web/` — само приложение (сайт). `config.js` — адрес и ключ сервера.
- `supabase/setup.sql` — база: вставить в Supabase → SQL Editor → Run.
- `android/` — Android-приложение (показывает `web/` внутри себя).
- Каждый push в `main`: сайт публикуется на GitHub Pages (ветка `gh-pages`),
  `Semya.apk` появляется в разделе Releases.

## Ограничения первой версии
- Уведомления и входящие звонки приходят, пока приложение открыто или свёрнуто недавно.
  Когда телефон надолго уснул, Android обрывает связь (для этого нужны push-уведомления Firebase).
- Звонки — один на один. В некоторых мобильных сетях для звонков нужен TURN-сервер
  (добавляется в `config.js` → `iceServers`).
- Код приглашения меняется в Supabase: таблица `app_config`, строка `invite_code`.
